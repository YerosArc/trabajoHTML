# Trabajo final HTML/CSS - Tempus Relojería

Autor: Mario García

Sitio web de una empresa ficticia de relojes realizado con HTML5 y CSS3.

## Enlaces

- Repositorio de GitHub: https://github.com/YerosArc/trabajoHTML
- Sitio web en GitHub Pages: https://yerosarc.github.io/trabajoHTML/

## Estructura del proyecto

- index.html: página de inicio
- views/productos.html: galería de productos
- views/presupuesto.html: formulario de presupuesto
- views/contacto.html: mapa y datos de la empresa
- css/estilos.css: hoja de estilos
- images/: imágenes del sitio
